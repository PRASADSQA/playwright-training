# 🎭 Playwright 0 → Pro Automation Project

A structured learning and implementation project designed to build professional-level expertise in **Playwright end-to-end automation** using **TypeScript**, industry best practices, and real-world web applications.

This repository demonstrates progressive learning, automation framework design, Git version control discipline, and automation of a public Swedish production website.

---

## 🎯 Objectives

- Build strong fundamentals in Playwright automation
- Design scalable test architecture using Page Object Model (POM)
- Practice professional Git workflows
- Implement CI-ready test execution
- Automate real-world user scenarios on a Swedish public service application
- Demonstrate industry-grade automation practices

---

## 🚀 Tech Stack

- Playwright
- TypeScript
- Node.js (LTS)
- Git & GitHub
- GitHub Actions (CI)
- VS Code
